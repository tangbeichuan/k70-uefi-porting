## 驱动之间的依赖顺序（APRIORI 里的相对位置）

```
Pcd.inf → VermeerDtbExtnDxe（provider，最早）
        → … 厂商驱动（EnvDxe/PmicDxe/DALTLMM/UFSDxe…） …
        → VermeerLogDiskDxe（BDS+2s 定时器做 USB 诊断）
        → VermeerMenuDxe（永不返回，必须是最后一个自研驱动）
```

## 编译注意

- INF 必须有 `[LibraryClasses] UefiDriverEntryPoint`（否则 `lld-link: undefined symbol: _ModuleEntryPoint`）。
- 用 `gDS->*` 需要 `DxeServicesTableLib`。
- 用 `GetSectionFromAnyFv` 需要 `DxeServicesLib`。
- 源码必须从 `port-drivers/<模块名>/` 拷贝进仓库树，构建脚本会在每轮开头覆盖。
