## 结论一句话

## 已知"看似故障其实正常"的现象

1. **几秒后自动关机**：BDS 找不到可启动设备 → `ResetSystem(EfiResetShutdown)` → PSCI `SYSTEM_OFF`。**不是崩溃**。
2. **`Memory Allocation …` 刷屏**：Mu 的 DEBUG 输出，正常。
3. **`Error: Image at … start failed: No mapping`**（`RscDxe`）：该 FD 段未映射，非致命。
4. **`ButtonsInit: failed to locate PmicGpioProtocol`**：我们摘掉 `PmicDxe` 的那些版本才会出现；保留 `PmicDxe` 后消失。
5. **`[DTBEXTN] get node … -> 0x0` 后没有后续**：该厂商驱动在等一个我们还没实现的接口方法。

## 下一步（按优先级）

1. **EP0 描述符应答**（`keys168` 已铺好路标）：主机已经在要描述符（`VID_0000&PID_0002`），只差应答。
2. USB 通之后 → CDC-ACM（COM 口）把 UEFI 日志直接流到 PC，彻底摆脱拍照。
3. UFS：`wr(0x58,1)` 门铃挂死的根因（SMMU 旁路 / UTRD 字段 / PHY 上电）。
4. 有 BlockIO 后 → FAT/ESP → 菜单第一项真正能启动 Linux / UniXNU。
